# Architecture Decision Records

This directory stores durable architecture decisions for DS4.

Use an ADR when a decision affects runtime boundaries, model correctness gates, data/marker policy, project scaffolding, or agent workflow. Keep transient status in `progress.md` or `training-next-status.md` instead.

## Template

```markdown
# ADR NNNN: Title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded

## Context

What forces or constraints led to this decision?

## Decision

What did we decide?

## Consequences

What becomes easier, harder, or explicitly out of scope?
```
